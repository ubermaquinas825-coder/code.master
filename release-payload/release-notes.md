Aplicativo portátil para **Windows 10/11 x64 (Intel/AMD)**.

### Como usar

1. Baixe **Atelie-de-Arte-Windows-x64.exe** nos arquivos desta release.
2. Dê dois cliques e aguarde a abertura.
3. Crie sua conta local na primeira utilização.

Não precisa instalar Node.js, npm nem executar comandos. Seus dados ficam no perfil do usuário do Windows. OpenAI é opcional e pode ser configurada em **Aplicativo → Configurar OpenAI**.
