# Ateliê de Arte para Windows

Aplicativo independente para trabalhar com imagens, recortes, vetorização, mockups e exportações.

[**Baixar instalador Windows x64**](https://github.com/ubermaquinas825-coder/code.master/releases/download/v0.1.1-windows/Atelie-de-Arte-Instalador-Windows-x64.exe)

Abra o instalador e aguarde a instalação. Depois use o atalho **Ateliê de Arte** na área de trabalho ou no menu Iniciar. Na primeira utilização, crie sua conta local. Não precisa instalar Node.js nem executar comandos.

Como alternativa, baixe o [ZIP de pasta completa](https://github.com/ubermaquinas825-coder/code.master/releases/download/v0.1.1-windows/Atelie-de-Arte-Windows-Pasta-Completa.zip), escolha **Extrair tudo** e abra `Atelie-de-Arte.exe` de dentro da pasta extraída. Mantenha os demais arquivos e subpastas juntos com o executável.

Windows 10/11 de 64 bits, x64 Intel/AMD. Reserve pelo menos 2 GB livres, além do espaço das imagens. Os dados ficam no perfil do usuário, separados dos arquivos do programa. A integração com OpenAI é opcional e pode ser configurada no menu Aplicativo; nenhuma chave está incluída.

A revisão 0.1.1 muda a distribuição Windows e preserva o núcleo da versão 0.1.0. O antigo executável autoextrator foi substituído para evitar a extração silenciosa em cada abertura.

O instalador e o ZIP final foram abertos em Windows Server 2025 x64, verificando janela, interface, backend e uma segunda execução. [Teste nativo e publicação](https://github.com/ubermaquinas825-coder/code.master/actions/runs/39451569819). A [release](https://github.com/ubermaquinas825-coder/code.master/releases/tag/v0.1.1-windows) inclui instruções, checksums SHA-256 e o relatório de validação. Os pacotes não têm assinatura digital comercial.

Este repositório contém a distribuição e os arquivos de empacotamento e validação. O código-fonte do aplicativo não foi publicado aqui.
