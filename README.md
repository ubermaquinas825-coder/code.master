# Ateliê de Arte para Windows

Aplicativo portátil para Windows 10/11 x64 (Intel/AMD).

## Download

Baixe **Atelie-de-Arte-Windows-x64.exe** na [página de releases](https://github.com/ubermaquinas825-coder/code.master/releases/latest).

Dê dois cliques no executável e crie sua conta na primeira abertura. Não precisa instalar Node.js nem executar comandos. Contas, projetos e artes ficam no notebook. Para configurar a integração opcional com OpenAI, use **Aplicativo → Configurar OpenAI**.

O executável não possui assinatura digital comercial. A aplicação e seus 45 testes foram validados em Linux, incluindo uma janela real do Electron; a execução nativa no Windows permanece como validação no notebook de destino. O SHA-256 acompanha cada release.

A versão inclui ferramentas locais de recorte, vetorização, ampliação, remoção de fundo uniforme, mockups 2D/3D e exportações. OpenAI requer internet, chave e modelo próprios; não há chave embutida.
